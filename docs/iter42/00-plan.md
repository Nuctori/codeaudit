## 问题域：B 表 14 项 + M_out 7 通道的"假纯可能"族

technical-debt.md 方向分类三值：安全-过近似（S2 内，可接受）/ 安全-未知（判别力损失）/ **假纯可能（S1 现实违反，必须入 M_out）**。

假纯可能通道 = 工程妥协的形式化硬核，共 4 族：

| 族 | 条目 | 本质 | 形式化出路 |
| --- | --- | --- | --- |
| 事件订阅 | B4/M1 | 运行时回调：触发不确定 → 不建边 → 订阅/触发方假纯 | **建边（S2 过近似）**：事件声明为间接层，订阅点 + 触发点双通道 |
| 开放世界 | B8/M2（项目外子类）、M3（项目外状态写者）、B12/M4（Python `__new__`/monkey-patch） | 模型外代码不可静态可见 | 无静态解？→ 形式化为**外部假设参数化**（Σ_ext 声明），或维持文档化 |
| 类型加载 | B14（静态初始化器并入 new C()） | 过近似合并了两个不同事件（类型加载 vs 实例化） | **chunk 分解**：静态初始化器独立 chunk → 标注单元细化（格不变，A6 无新原子） |
| 属性读取残余 | M5/M6（已修）、M7（enum 读取落 ?） | 判别力损失 | M7 小数据化（enum_declaration 入 classNodes） |

安全-过近似族（B1/B2/B3/B6/B13）与安全-未知族（B3/B7/B17）：不是"假纯"问题，是**精度**问题——候选：

- B13 单接口基类：knownInterfaceNames 数据表（收益小）
- B2 组件效应细分（io 读/写）：需效应格重定义（A7 原子集扩展）——风险高，预期延后
- B1 效应表校准：数据债非形式化，已有注入通道部分缓解

## 候选落地清单（评审裁决 do-now / do-later / defer）

### 候选 1（主推）：事件订阅建模——B4/M1 假纯通道闭合

**现状**：link 零实现；fixture test/fixtures/csharp/EventSubscribe.cs 存在但无断言（事件不建模）。
**形式化设计**（S2 方向，消除假纯，接受过近似）：

- 事件声明 = **间接层节点**（不独立 chunk，只作边汇聚点，与 import 通道同族：别名解析）。
- **订阅边**：`evt += handler`（同一类内跨方法可关联）→ 订阅集合 `sub(evt) = {handler}`。
- **触发边**：`evt.Invoke()` / `evt?.Invoke()` → 对 `sub(evt)` 全展开建调用边（**悲观并集**，触发不确定性不再是"不建边"的理由——S2 语义：可能执行 = 效应必须传播）。
- **作用域**（第一版保守）：仅类内自事件（`evt` 为 bare identifier 且类内声明）；`other.evt += h` 跨类订阅 → 落 `?`（诚实，与对象流同族）。Unity `AddListener` 形态同表提取（AddListener 为成员级方法表，不硬编码）。
- **方向**：安全-过近似（多报）；触发方 getter 化效应链——`Raise()` 调 `OnLevelChanged?.Invoke()` → 展开 HandleLevel。与 B5 属性读取同构（间接层 + 展开）。
- **残余**（入 M_out 更新）：跨类订阅、动态添加/移除订阅（`-=` 时序）、UnityEvent 跨对象派发——声明触发条件。

### 候选 2：静态初始化器独立 chunk——B14 标注精度

**现状**（L5，iter39）：ctor 分支并集闭包全部 class chunk 原始调用（字段初始化器效应并入 new C()）——`new C()` 多报静态初始化器效应。
**形式化**：类型加载事件 ≠ 实例化事件。**独立 chunk `C::<static-init>`**（static 字段初始化器 + 静态构造器体），new C() 的并集闭包改含该 chunk。
**关键性质**：**行为零变化**（闭包内容不变），但标注单元细化——AI 可单独标 `C::<static-init>` PURE，new C() 的过近似随之解除。格不变（无新效应原子），A6 无破坏。
**风险**：与 L5 刚修的"字段初始化器归入 class chunk"边界交互（实例字段初始化器仍归 class chunk；仅 static 修饰符的分离）。

### 候选 3（小）：M7 enum 读取——安全-未知 → 判纯

enum_declaration 入 classNodes（与类同解析）→ `Color.Red` 读取不再落 `?`（C# 静态语义：enum 成员无用户代码）。方向安全，判别力收益。

### 候选 4（预期延后）：B13 接口清单

knownInterfaceNames 数据表消残余；收益小（"类侧残余罕见"自述）。

### 候选 5（预期延后）：B2 效应细分

效应格扩展（io-read/io-write 原子）——A7 原子集 + 全部语言包 + 渲染层连锁。风险大收益小。

### 候选 6（预期延后）：开放世界形式化（M2/M3/M4）

请数学家裁决：**Σ_ext 外部假设参数化**（CLI 声明"项目外无覆写"→ 关闭过近似）是否有价值，还是纯文档化维持 M_out。倾向：无消费者需求，defer。
