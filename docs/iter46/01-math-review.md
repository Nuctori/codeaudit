## 一、逐候选数学审计

### C 可规约性 / SCC 入口 —— **数学正确，采纳（并入 graphMetrics）**

**定理（Hecht-Ullman 1972）**：流图可规约 ⟺ 无多入口循环 ⟺ T1（去自环）+ T2（合并单前驱）可约简为单节点。对调用图：SCC 凝聚后 DAG 天然无环，可规约性**归约为每个 SCC 的外部入口数**——

- 单入口 SCC（外部入边进入同一节点）：**结构化递归**——递归头唯一，T2 可约简，模块内聚。
- 多入口 SCC（外部入边进入 >1 个不同节点）：**纠缠递归**——多个调用者分别进入环的不同节点，模块互锁。

数学性质：入口数在调用图上是良定义且精确可算（O(E) 单遍），**不同于被砍的 λ₂**（依赖无向化对称 + 特征分解，近树图多分量恒 0）。与既有 cyclicComponents（topology.ts:84 同源）只差 pred 计数，是「统计型」家族的自然扩展。

### A 传递约简 —— **数学正确但规模受限，采纳修正形态（凝聚/文件级）**

**定理（DAG 传递约简唯一性）**：DAG 的传递约简存在且唯一（Aho-Garey-Ullman 1972）——删除可由路径推导的边，保可达性。

**必须澄清的语义**：骨架是**报告层**变换（揭示「最小依赖集」），**不是判定通道**变换——A→C 与 A→B→C 并存的效应语义（纯度判定中直接边与传递路径的效应并集不等价，A→C 独立信息）在骨架中不丢失：骨架只**标记**冗余边，不删除原始边（纯函数输出新集合，verdicts 不可变）。

**规模定理**：朴素 chunk 级 O(V·E)=8.63e8（28K 图分钟级）不可行；凝聚级（83+ 分量）/文件级（3K）近树图 Σ|reach| ≈ V·depth ≈ 6e5 毫秒级。读者粒度（模块/文件决策）恰在可算规模内——**数学正确形态 = 凝聚/文件级**。

### 割点/桥（评审补入候选）—— **数学正确，采纳**

无向化凝聚图上的桥 = 唯一连通通道（删边即隔离）；割点 = 枢纽分量。O(V+E) Tarjan 变体，与既有 tarjan.ts 同设施。数学上与影响面互补：影响面 = 下游集合（fan-out 语义），桥 = 结构断点（边连通性语义）。近树图上**非平凡**：83 个 SCC 之间的连接边绝大多数是桥（树状），桥清单直接给出「模块边界的单点耦合」。

### B 模块分解 —— **数学上无错但稀疏图无信息，否决（与谱诊断同类）**

modular decomposition（cotree）对稠密/结构化图有效；**稀疏近树图上分解树几乎全是 prime 节点**——「模块」退化为单点，信息为零。Habib-Paul 自实现 300-600 行无 oracle（node_modules 无 graph 库实证），正确性风险高。降级（连通分量 + --modules 目录聚合 + 割点/桥）已覆盖读者。**判决与迭代12 谱诊断一致：可行性不构成做它的理由。**

### D 行为等价商图 —— **数学良定义但无动作语义，否决**

bisimulation 商图（同调用者集 ∧ 同被调用者集 ∧ 同效应 → 合并）在标签图上良定义，partition refinement O(E log V) 便宜。但价值 = 报告压缩：重复 chunk 已各自正确判定（v2 报告 Generated 1063 chunks 全纯），商图不改变任何判定、不新增行动（生成代码去重的行动已是 R1）。**显示关切非审计语义——YAGNI。**

### E 支配树 —— **与既有设施重叠，否决**

Lengauer-Tarjan O(E·α) 自实现 150-200 行 + 多入口调用图需虚拟根；近树图支配关系平凡（单父链），与 layer/dagDepth/chain（topology.ts:97-122 已算）边际信息 ≈0。

### 候选 6 k-core —— **暂缓（近树图恒浅）**

度数迭代剥离在密度 0.000 的图上 k-core ≤2 恒浅，无「耦合核心」可挖。图证据变化（模块级密度 >0.05）再启用——现属无读者。

## 二、「可规约、最小化」的数学本质

用户问题的形式化：给定 chunk 调用图 G=(V,E)（SCC 凝聚后 DAG G'=(C,E')），存在分析 F 使：

- **可规约**：F 揭示 G' 的每个强连通单元是**结构化递归**（单入口，T2 可约简）还是**纠缠递归**（多入口）——可规约性 = 递归结构的良构性度量；
- **最小化**：F 给出 G' 的**最小表示**——传递约简骨架（唯一，保可达性）+ 桥/割点（唯一连通断点）——「最小依赖集 + 最小隔离点集」。

**结论：存在，且是组合图论的标准工具**（非谱/非概率），全部 O(E)~O(V+E) 量级，在 28K 图上毫秒级可算。与既有 graphMetrics 家族（统计型）互补：本轮三件是**结构型**。

## 三、评审问题逐条回答

1. **最有力候选**：C（「可规约」字面义 + O(E) 最低 + 数学精确可算）；A 是「最小化」字面义但必须限规模；割点/桥是「模块边界」字面义。
2. **A+B 互补？** 不互补——B 稀疏图退化；A 骨架 + 桥 + --modules 聚合才是互补三元组。C 并入 graphMetrics（同族统计型，独立 API 割裂）。
3. **输出形态**：库 API 纯函数（D-065）+ CLI additive（--topology 一行 / --deps 注记），不加新旗标。
4. **B 自实现 vs 降级**：降级（无库可用 + 无 oracle + 稀疏图无信息）。
5. **与谱诊断同类？** B/D 是（砍）；E 部分（重叠）；C/A/桥不是——三者均有已存在读者动作。
6. **漏掉的**：割点/桥（最重要）；逐节点杠杆排序（可选，与 forwardClosure 重叠）；介数中心性明确排除（O(V·E) 28K 不可行）。
